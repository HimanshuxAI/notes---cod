## What's Inside

### Unit III — Cloud Security, Monitoring & Cost Management (8 Hours)
- Authentication vs Authorization (CIA triad, OIDC, OAuth 2.0, RBAC, JWT, SAML)
- Confidentiality, Integrity, Availability (AES, DES, VPN, hashing, DoS/DDoS)
- Infrastructure Security (Security Groups, NACLs, WAF, AWS Shield, IAM)
- Data Security & Storage (privacy, jurisdictional issues, IAM policies)
- Cloud Service Agreements (CSAs)
- Cost Management (fixed vs variable expenses, billing)
- Monitoring & Troubleshooting (CloudWatch, SNS, CloudTrail)
- 10 exam questions with detailed model answers

### Unit IV — Containerization and Orchestration (9 Hours)
- Introduction to Containers (Docker, benefits, ecosystem)
- Containers vs Virtual Machines (comparison)
- Kubernetes (K8s) — architecture, pods, deployments
- Autoscaling (HPA, VPA, Cluster Autoscaler)
- Microservices Architecture (stateless vs stateful, pros/cons)
- Serverless Computing (BaaS vs FaaS)
- 10 exam questions with detailed model answers
