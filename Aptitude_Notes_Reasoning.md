# PART 1 — BLOOD RELATIONS

## 1.1 Basic Rules & Generations

Blood relation questions study **3 generations**:
1. Grand Parents
2. Parents  
3. You

## 1.2 Key Relationship Terms

| Relationship | Term |
|-------------|------|
| Mother's/Father's son | Myself / Brother |
| Mother's/Father's daughter | Myself / Sister |
| Mother's/Father's brother | Uncle |
| Mother's/Father's sister | Aunt |
| Mother's/Father's father | Grandfather |
| Mother's/Father's mother | Grandmother |
| Son's wife | Daughter-in-law |
| Daughter's husband | Son-in-law |
| Husband's/Wife's sister | Sister-in-law |
| Husband's/Wife's brother | Brother-in-law |
| Brother's son | Nephew |
| Brother's daughter | Niece |
| Uncle/Aunt's son/daughter | Cousin |
| Sister's husband | Brother-in-law |
| Brother's wife | Sister-in-law |
| Grandson's/Granddaughter's daughter | Great-granddaughter |

## 1.3 "Only" Concepts

- **Only son of my father** = Myself (if male) or Brother (if female)
- **Only daughter of my mother** = Myself (if female) or Sister (if male)
- **Only son of my paternal grandfather** = Myself/Father's brother
- **Only daughter of my paternal grandmother** = Myself/Father's sister
- **He is the son of only brother of husband of my mother** = My cousin (mother's brother's son)

## 1.4 Coded Blood Relations

Symbols represent relationships. You must decode the expression step-by-step.

**Example codes:**
- `X + Y` = X is the father of Y
- `X × Y` = X is the brother of Y
- `X – Y` = X is the mother of Y
- `X ÷ Y` = X is the sister of Y

**Approach:** Start from the person whose relation is asked, work backwards through the expression.

## 1.5 Common Question Types

| Type | Description |
|------|-------------|
| Direct relation | "How is A related to B?" |
| Family tree | 6-9 members, multiple statements |
| Portrait/Photograph | "Looking at a portrait, X said..." |
| Coded relations | Symbol-based expressions |
| Data sufficiency | Which statements are necessary? |
| Gender determination | Can gender be determined or not? |

## 1.6 Solving Tips

- Draw a family tree diagram
- Use `+` for male, `-` for female, `=` for married couples
- For "only" statements, identify the single person in that generation
- For portrait questions: "My father's son" with "no brothers/sisters" = Myself
- For coded relations, convert symbols to words first, then trace

# PART 2 — SYLLOGISM

## 2.1 Qualifiers

| Qualifier | Examples | Meaning |
|-----------|----------|---------|
| **All** | All A are B | Universal affirmative |
| **No** | No A is B | Universal negative |
| **Some** | Some A are B (few, most, many) | Particular affirmative |
| **Some-not** | Some A are not B (not all, all-not) | Particular negative |

## 2.2 Key Conversions

| Original | Equivalent |
|----------|------------|
| Some A can never be B | Some A are not B |
| Only A are B | All B are A |
| All A can never be B | Some A are not B |
| A is not B | No A is B |
| A is B | All A are B |
| Some A are definitely not B | Some A are not B |

## 2.3 Syllogism Types

| Type | Structure |
|------|-----------|
| **Type 1** | Basic syllogism — one conclusion from two statements |
| **Type 2** | Two statements, two conclusions (I & II) |
| **Type 3** | Third statement follows from first two |
| **Type 4** | Third statement concluded from first two |
| **Type 5** | Three statements, three conclusions |
| **Type 6** | Three statements, four conclusions |
| **Type 7** | Conclusions with "may be / can be / possibility" |
| **Type 8** | Either–Or cases |

## 2.4 Answer Options (Type 2)

| Option | Meaning |
|--------|---------|
| (A) | Only Conclusion I follows |
| (B) | Only Conclusion II follows |
| (C) | Neither I nor II follows |
| (D) | Both I and II follow |

## 2.5 Venn Diagram Rules

- **All A are B:** Circle A is inside circle B
- **No A is B:** Circles A and B are separate (no overlap)
- **Some A are B:** Circles A and B overlap
- **Some A are not B:** Part of circle A is outside circle B

## 2.6 Possibility Cases

| Statement | Possibility Conclusion |
|-----------|----------------------|
| Some A are B | All A are B (possible) / All B are A (possible) |
| All A are B | Some B are A (definite) / Some A are B (definite) |
| No A is B | No possibility of overlap |
| Some A are not B | All A are not B (possible) / Some A are B (possible) |

## 2.7 Either–Or Case

Applies when:
- Both conclusions are of the same type (one positive, one negative)
- Both have the same subject and predicate
- Neither conclusion definitely follows individually
- One of them must be true

**Example:** Some cars are buses. All buses are trucks. No truck is train.
- I. Some cars are trains × II. No car is train → **Either I or II**

# PART 3 — FACT, INFERENCE & JUDGEMENT

## 3.1 Definitions

| Type | Definition | Clues | Example |
|------|-----------|-------|---------|
| **Fact** | Something you can see, feel, touch, hear. Verifiable (true or false). | Numbers, stats, dates, names | "Sun rises in the East" |
| **Inference** | Conclusion derived from evidence or data. Logical deduction. | "Therefore", "leads to", "may" | "Smoking causes lung disease, smokers at risk from COVID" |
| **Judgement** | Opinion. Not universal. Varies person to person. | Adjectives, proverbs, sayings | "People using Apple products are cool" |

## 3.2 How to Identify

**Fact:**
- Contains verifiable information
- Numbers, statistics, historical dates
- Can be proven true or false
- Examples: "Sachin began career in 1969", "Vultures have sharp claws"

**Inference:**
- A conclusion based on given facts
- Words like "leads to", "therefore", "may cause", "precursor to"
- Examples: "Factory smoke causes air pollution and this may lead to harmful effects"

**Judgement:**
- Subjective opinion
- Adjective words (best, delicious, beautiful, cool)
- Proverbs and sayings
- Examples: "This cake is delicious", "Apple products are cool", "Dalgona coffee is the best"

## 3.3 Question Format

Four statements are given, each labeled F (Fact), I (Inference), or J (Judgement). You must select the correct sequence (e.g., FFFF, FIJJ, FJFI, IFJF).

**Example:**
1. It's raining outside and birds are chirping — **Fact**
2. Sachin is the best batsman and will remain so — **Judgement**
3. There is vaccine shortage in the city — **Fact**
4. Sleeping late leads to health problems — **Inference**
Answer: **FJFI**

## 3.4 Practice Examples

| Statement | Type | Reason |
|-----------|------|--------|
| Cadbury chocolate has blue wrapping | Fact | Verifiable physical attribute |
| All Cadbury chocolates are delicious | Judgement | Opinion ("delicious") |
| Owls are intelligent compared to Falcons | Judgement | Subjective comparison |
| It is inauspicious to keep bird of prey paintings | Judgement | Superstition/opinion |
| Too much caffeine causes high blood pressure | Fact | Medical fact |
| Dalgona coffee craze has to do with Covid isolation | Inference | Conclusion from observation |
| Ludo King has Voice Chat, 6 Player Ludo | Fact | Verifiable feature |
| Cricket in India is not just a game | Judgement | Opinion |
