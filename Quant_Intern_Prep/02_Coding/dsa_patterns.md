# ⚡ DSA Patterns for Quant Coding Rounds

Quant shops ask easier DSA than big-tech, but they still filter on it. Know these patterns:

---

## 1. Array / String
- Two pointers (sorted array, container with most water)
- Sliding window (max sum subarray of size K, longest substring)
- Prefix sum (range sum queries, subarray sum equals K)
- Dutch national flag (sort 0s/1s/2s)

## 2. Hashing
- Frequency counting (first unique char, anagram check)
- Two Sum / 3 Sum using hash map
- Group anagrams

## 3. Stack / Queue
- Valid parentheses
- Min stack
- Monotonic stack (next greater element)

## 4. Recursion / Backtracking
- Generate permutations, subsets, combinations
- N-Queens (sometimes)
- Flood fill

## 5. Trees / Graphs
- BFS/DFS (grid traversal, number of islands)
- Binary tree traversals (in/pre/post order)
- BST properties

## 6. Heap / Priority Queue
- Merge K sorted lists
- Top K frequent elements
- Kth largest element

---

## 7. Quant-Specific Twists

- Generate a uniform random number from a non-uniform source (e.g., biased coin → fair coin).
- Shuffle an array (Fisher–Yates).
- Reservoir sampling (pick k random from a stream).
- Running median (two heaps).
- Simulate dice rolls / card draws and estimate probability.
